# 示例

## 正四棱台2023真题演示.html

2023 新高考Ⅰ卷正四棱台题的完整产出，可作为 `assets/template.html` 的填充范例。

**题目**

正四棱台 `ABCD-A′B′C′D′` 中，`AB = 2A′B′`，点 `P` 为棱 `CC′` 上一点。

1. 记棱锥 `P-BCD` 的体积为 `V₁`，棱台被它分出的另一部分体积为 `V₂`，当 `PC = PC′` 时，求 `V₁ : V₂`。
2. 若正四棱台侧棱与底面所成角为 `π/3`，当平面 `A′BD ⊥ 平面 PBD` 时，求直线 `PA` 与平面 `PBC` 所成角的正弦值。

**答案**

| 问 | 结果 |
|---|---|
| (1) | `V₁ : V₂ = 1 : 6` |
| (2) | `sin θ = 4√273 / 91 ≈ 0.7263`，垂直条件解出 `t = 1/2`（P 恰为 CC′ 中点） |

**页面能力**

- 拖动 P 点沿棱 CC′ 滑动 → 两面夹角从 60° 增至 **90°（t = 1/2 处）** 再回到 60°，实时读数
- 点顶点高亮（多选）→ 讲面对角线、异面直线时多点同时亮
- 开关：棱台实体 / 平面 A′BD / 平面 PBD / 棱锥 P-BCD / 空间坐标系
- 双端可用（电脑静态侧栏，平板抽屉式面板）

**打开方式**

直接双击即可（走 CDN 加载 Three.js）。
**离线使用**需把 three.js r146 的 `build/three.min.js` 放到本目录，页面会自动兜底加载。
