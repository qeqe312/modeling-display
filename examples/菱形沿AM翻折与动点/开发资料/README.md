# 开发资料

构建入口 `build_demo.py` 直接读取本例 `源码/layout.html`、`style.css`、`model.js` 和 `engine.js`，按顺序组装后用仓库校验过的 Three.js 打包为单文件。无需其他题目的源码或历史版本。

`check_math.mjs` 是独立数学证明检查；`check_browser.py` 在最终离线成品上运行鼠标与可信触摸输入；`inspect_demo.py` 生成桌面、平板横竖屏和手机的截图。最新证据见 `验证记录/`。

工作 HTML 位于本目录，成品位于上一级 `成品/`，可读源码位于 `源码/`。保留 `题目/原题.png` 和题意记录。使用方法见 `使用说明.md`，改编指南见上一级 `REFERENCE.md`。
