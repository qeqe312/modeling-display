# 正四棱台2023真题演示 · 完整解题版

双击打开同目录的 `正四棱台2023真题演示.html`，无需联网或安装程序。单文件已内嵌 Three.js r146。`离线双文件版` 为相同页面与本地库分离的版本，移动时保留整个文件夹。

## 使用

- 默认 P 在 CC′ 中点，平面 A′BD、PBD 和线面角辅助图层同时显示。完整推导全部展开。
- 直接拖动橙色 P 小球或字母 P，使它沿 CC′ 运动。抓住 P 时相机锁定，松手后恢复。轻点顶点或字母可多选高亮，再点取消。
- “显示设置”顶部提供位置滑条、C / 中点 / C′ 快捷按钮、PC : PC′、体积比及角度读数。
- 拖动空白旋转，鼠标滚轮缩放、右键或 Shift 拖动平移；平板单指旋转、双指缩放和平移。
- 平板点击“题目 / 设置”。竖屏底部抽屉，横屏左侧抽屉，解答连续滚动。点击主画面的公式可定位推导，并保留图层和 P 的位置。
- 图层、顶点字母、边长、字号、棱台面透明度、多选清空和画面精细度均可独立调节。
- “复位视角”或“居中”只调整视角；回到题设位置请用显示设置中的“中点”。

## 数学模型

题目沿用项目原有的正四棱台示例，保留原题条件，不额外断言试卷出处。

第（1）问设上底边长 a、下底边长 2a、棱台高 h：V = 7a²h/3，P 为中点时 V₁ = a²h/3、V₂ = 2a²h，答案为 **1 : 6**。

第（2）问按相似关系取 a = 1，h = √6/2。教学坐标 z 轴竖直向上，P = (1−t/2, 1−t/2, ht)，t = PC/CC′ ∈ [0,1]。两平面垂直对应 t = 1/2，所求 **sin θ = 4√273/91 ≈ 0.7263**。F 为 A 到平面 PBC 的垂足，位于该平面的延伸部分。

右上角与设置中的读数跟随当前动点；底部公式和完整推导给出题设条件下的答案。P = C 时三点 P、B、C 不能确定平面，因此线面角显示“未定义”，其余读数仍可使用。
