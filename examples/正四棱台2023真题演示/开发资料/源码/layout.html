正四棱台 ABCD–A′B′C′D′ 中，AB＝2A′B′，点 P 在棱 CC′ 上。

（1）记棱锥 P–BCD 的体积为 V₁，棱台被它分出的另一部分体积为 V₂。当 PC＝PC′ 时，求 V₁ : V₂。

（2）若侧棱与底面所成角为 π/3，当平面 A′BD ⊥ 平面 PBD 时，求直线 PA 与平面 PBC 所成角的正弦值。

两问的解题位置都是 CC′ 的中点。直接拖动橙色 P，观察垂直条件与读数怎样变化；精确调节在“显示设置”中。

01

第（1）问：整体减去小棱锥

设上底边长为 a，下底边长为 2a，棱台高为 h。本问不需要用到侧棱与底面的夹角。

V＝h / 3 · (a²＋4a²＋√(a²·4a²))
＝7a²h / 3

△BCD 占下底正方形的一半，面积为 2a²。P 是 CC′ 的中点，所以它到底面的距离为 h / 2。

V₁＝1 / 3 · 2a² · h / 2＝a²h / 3
V₂＝V－V₁＝2a²h
V₁ : V₂＝1 : 6

V₂ 是剩余部分，不能把 V₁ 与整体 V 的比 1 : 7 当作答案。

03

垂直条件确定 P 的位置

由两个平面内不共线向量的叉积，可分别取平面 A′BD 与平面 PBD 的法向量：

n₁＝(2h, 2h, 2)
n₂＝(2ht, 2ht, 2t－4)

两平面垂直，等价于它们的法向量点积为 0。代入 h²＝3 / 2：

n₁·n₂＝8h²t＋4t－8
＝16t－8＝0
t＝1 / 2，P 为 CC′ 中点

拖动 P 时，右上角显示的是两平面的锐夹角；回到中点，夹角恰为 90°。

04

用法向量求线面角

中点 P＝(3/4, 3/4, h/2)。平面 PBC 可取法向量 n＝(2h, 0, 1)，从而：

PA＝(−7/4, −7/4, −h/2)
|PA|＝√26 / 2，|n|＝√7
|PA·n|＝4h＝2√6

记所求线面角为 θ。图中 F 是 A 到平面 PBC 的垂足，PF 是 PA 在该平面上的投影，θ＝∠APF。

sin θ＝|PA·n| / (|PA| · |n|)
＝4√6 / √182＝4√273 / 91
0.7263θ ≈ 46.57°

两问答案：（1）1 : 6；（2）4√273 / 91。
