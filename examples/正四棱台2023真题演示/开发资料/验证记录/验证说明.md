# 本版验证记录

2026-10-04，Windows 本机 Chrome；离线 file:// 页面测试。以下结果记录当次运行情况，复现时可使用自己的 Python 环境，无需维护者的个人安装路径。

- `check_math.mjs`：317 项独立断言通过。核对第一问任意尺度与高度下的体积比、叉积法向量、全棱采样的两面角和线面角、垂足、精确答案。
- `check_browser.py`：187 项检查通过，完整列表与指标见 `browser-report.json`。鼠标和触摸由浏览器真实输入路径触发；触摸使用 CDP Input.dispatchTouchEvent，检查 PointerEvent.isTrusted，不使用合成 PointerEvents 代替。
- 404 个透视反解采样（含相机平移与视口偏移），最大误差约 7.72×10⁻¹⁵。鼠标/CDP 输入坐标使用浏览器浮点精度，交互检查的 t 容差为 2×10⁻⁵；不以输入量化误差评价解析公式。
- P 在 C/C′ 重合时仍优先捕获动点；拖出棱段后限制在端点。模型与滑条双向同步，拖点期间相机方位、高度、距离和目标全部不变，不误选顶点。
- 第二根手指加入动点拖动时不解除相机锁定；取消、松手后释放捕获。单指旋转、双指缩放和平移、顶点多选均通过。
- 820×1180 竖屏底部抽屉、1180×820 横屏左侧抽屉；390×844、780×1000、1366×1024 额外尺寸验证。公式在视口内，顶点标签在正视、俯视与立体视角不互相覆盖，保持在公式面板上方。
- 图层开关操作实际模型对象，字号、透明度、文字、清空、多选、精细度均验证；定位公式保留图层与动点位置，全部解答保持展开。
- 将所有可选图层开启后，连续 90 次动态更新几何对象数量固定为 27；静止 600ms 时新增渲染帧数为 0。桌面渲染 CPU 提交与标签更新耗时 P95 会随环境及运行负载变化，最新值见 `browser-report.json`（不等于 GPU 完成耗时，不推断实体平板帧率）。报告同时记录实际浏览器版本与成品 SHA-256，可核对其对应版本。

## 复现入口

先阅读[本题 REFERENCE.md](../../REFERENCE.md)。激活自己的 Python 环境、确保 `node` 可用，在仓库根目录运行：

```powershell
python -m pip install playwright
python -m playwright install chromium
node "examples/正四棱台2023真题演示/开发资料/check_math.mjs"
python "examples/正四棱台2023真题演示/开发资料/check_browser.py"
python "examples/正四棱台2023真题演示/开发资料/inspect_demo.py"
```

浏览器脚本默认使用 Playwright Chromium。若使用自己安装的 Chromium 系浏览器，可设置 `GEO3D_BROWSER` 为其可执行文件路径；兼容别名为 `BROWSER_EXECUTABLE_PATH`，前者优先。重新运行会更新报告与截图；更换浏览器或设备后应按实际运行环境记录结果，仍不能把视口模拟视为实体平板验证。
