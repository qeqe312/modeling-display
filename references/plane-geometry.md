# 二维几何实现与复用

纯平面几何、解析几何、函数曲线或平面轨迹题先参考 [椭圆二维示例](../examples/椭圆动圆切线与定距离（二维）/REFERENCE.md)。需要空间翻折、空间角或立体关系时采用相应三维示例。二维保留共用页面结构与显示设置，采用 Canvas 2D，不加载 Three.js，也不使用球坐标相机。

## 可直接复用的平面引擎

复制本例的 `layout.html`、`style.css`、`app.js` 到新题工作目录。读 `REFERENCE.md` 的函数表，换原题、数学模型与图层；抽屉、标签、按需渲染、Pointer Events 的共用行为保留。构建外壳可参考该例 `build_demo.py`，改成读取新题自己的源码；不要让新题依赖原例或已删除目录。

视图只保存 `cx、cy、scale`，scale 是 CSS px / 教学单位。两个坐标轴必须用同一 scale，y 正向向上：

```text
screen(x,y) = (W/2 + (x−cx)·scale, H/2 − (y−cy)·scale)
world(px,py) = (cx + (px−W/2)/scale, cy − (py−H/2)/scale)
```

devicePixelRatio 只控制位图分辨率，不能混入命中容差、拖动距离或教学坐标。否则圆可能变椭圆，斜率/角度看起来失真。fit 依据新题包围范围计算，同时避开读数、工具栏和底部公式；不要照抄本题的坐标边界。

空白单指/鼠标拖动平移，滚轮缩放，以指针所在教学坐标作缩放锚点；双指同时缩放与平移。主参数拖动期间锁定全部 view 字段，第二指和滚轮不能抢占。单次按下只判定一次目标，取消/失焦/切方向清理捕获。

## 图形范围与实虚线

先区分直线、射线、线段，避免用“很长的双向线”代替所有对象。本例用户选择切线前向射线、MN 线段，延伸部分虚线；别的题目按题意决定是否显示整条直线或辅助延长线。

射线为 `X(t)=A+t·u，t≥0`。对屏幕矩形做参数区间裁剪，求可见 enter/exit；A 被平移到屏幕外时仍须正确裁剪。先裁剪，再根据主体实际边界把区间拆成实线与虚线，不按屏幕距离或 M/N 的左右顺序猜分界。虚线长和线宽保持 CSS 像素尺度，不随教学单位缩放。

本例 A＝(−2,0) 位于 `x²/4＋y²＝1` 边界，代入射线得到：

```text
t·[(ux²/4＋uy²)t−ux]＝0
t₂＝ux / (ux²/4＋uy²)
```

当 ux＞0，0 到 t₂ 在椭圆内；当 ux≤0，前向射线全在椭圆外。r＞2 时 M 在射线反向，因此不能为了“射线必须经过 M”而把朝向反转、破坏与圆的相切关系。页面应说明整条切线与显示射线的区别。

换椭圆、改变起点、或起点在主体内部时重新解边界方程，不能复用这个特殊 t₂。通用椭圆可把 `X(t)` 代入 `x²/a²＋y²/b²＝1`，得到二次式，用非负根和区间内外判定划分；新主体用它自己的求交逻辑。

## 受约束拖动与定义域

滑条、快捷按钮、圆周/手柄、动点都调用同一个参数更新入口。计算使用原值，格式化只在输出阶段。抓标签时保存参数偏移，避免按下瞬间跳动。

- 本题拖圆周：先 world 反变换，r＝|指针−D|，加抓取偏移后限制到[0,2√2]；D 始终不动。
- 本题拖 P：把指针投到以 Q 为心的辅助圆方向，角度限制到两段实际轨迹，m＝tan(角度/2)，再用 r＝√(4−32m/3)反解。
- 这两种反解属于本题，任意曲线、椭圆上的动点或多参数模型须另行推导；不能只把指针坐标写进点的位置。

数学允许画出的辅助圆不一定是动点的实际轨迹。展示全辅助圆时，用不同线型区分真实可达弧；标出排除点。交点重合、竖直斜率、零半径等情况下，隐藏未定义对象、清除命中矩形，读数写“未定义”；不要把极限值当端点值。

## 缓存、标签与交付

固定路径预建 Path2D；动态圆用单位圆路径做变换；拓扑不变时不用每次拖动创建路径。`invalidate()` 合并事件到一帧，静止时不持续渲染。标签保留深色胶囊与真实矩形命中，字号/选择/显隐变化才测量；普通拖动复用缓存。辅助图层的开关与标签有效性要同步。

二维单文件不需要 Three.js、在线字体或远程公式库。示例的构建器展示了 Canvas 外壳；已有 `assemble_demo.py` 和 `package_demo.py` 当前面向 Three.js，不要把它们不加区分地用到原生二维成品。

换题的验证至少涵盖：独立几何与最终答案、教学/屏幕坐标往返、缩放下的线型与命中、鼠标/可信触摸拖动及视图锁定、真实定义域/退化、实际图层效果、静止渲染及路径分配、桌面/平板横竖屏截图。保留浏览器沙箱，实机未测项单列。长期示例保存全部开发资料；普通新题交付 HTML、说明、许可证即可。
